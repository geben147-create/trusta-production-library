# 새 세션용 시작 프롬프트

이 저장소의 진행표에서 소유 범위와 다음 미완료 ID를 찾고 실제 집필을 이어가라. 천억뷰 세션은 EP001~EP995 홀수와 FAQ01·FAQ03, 캐나다 1위 세션은 짝수와 FAQ02·04·05다. 배정표와 해당 원본 프롬프트를 읽되 현재 사용자 지시가 우선한다.

은퇴 독자의 생활 장면으로 제목과 첫 질문을 잡아 하몬 서클 8단계로 작성한다. 조건이 바뀌는 두 사례와 직접 검산한 금액, 바로 해 볼 행동 한 가지를 넣는다. 공식 원문에 근거해 실측과 가상, 기간, 통화, 재투자, 비용과 세금을 구분한다. 출처 줄에는 기관과 자료명만 쓴다.

기존 시각자료를 확인하고 영상은 1920×1080으로 구성한다. 가로 수치 비교에서는 공통 축과 가독성 있는 숫자 라벨을 사용한다. 천억이나 수건 친구를 화면에서 유지한다. 신규 인스타 원페이지는 1080×1350이며 회차는 내부 파일명에만 둔다.

내레이션 JSONL을 작성하여 사용자가 지정한 로컬 Qwen3-TTS-Base 자연스러운 v2, 한국어 voiceB, -12 옵션으로 합성한다. 합성에 필요한 모델과 환경은 원래 작업 환경에서 확인한다. 실제 WAV로 1.2배속 순수 낭독 17분 초과 여부를 확인하여 재생 목차에 기록한다. 같은 ID의 진행 중인 합성을 다시 실행하지 않는다. 공개 발행 및 다음 세션의 예약은 별도 요청이 있을 때 한다.
