단, 허위 사실, 가짜 반전, 없는 인물 감정, 거짓 인용, 조작된 숫자, 억지 위기, 존재하지 않는 음모를 만들어서는 안 된다.

# 2. 가장 중요한 대본 원리

이 대본의 목적은 정보를 순서대로 나열하는 것이 아니다.

시청자의 머릿속에 만들어진 **현재의 정답을 계속 더 큰 정답으로 교체**해야 한다.

기본 구조:

상식
→ 상식과 충돌하는 사실
→ 첫 번째 설명
→ 설명을 입증하는 사건
→ 그런데 그 설명만으로 부족함
→ 두 번째 설명
→ 더 큰 사건
→ 다시 기존 결론 수정
→ 여러 원인을 하나로 묶는 원리
→ 현재의 시청자와 연결
→ 감정적·철학적 회수

핵심 원칙:

**새로운 정보가 나올 때마다 앞에서 본 정보의 의미가 조금 달라지게 만들어라.**

단순히:

사건 A
→ 사건 B
→ 사건 C

로 쓰지 마라.

반드시:

사건 A
→ 그래서 우리는 X라고 생각한다
→ 사건 B
→ 그런데 X만으로는 설명되지 않는다
→ 더 큰 설명 Y
→ 사건 C
→ 결국 X와 Y를 동시에 설명하는 Z

로 발전시켜라.


## [원문 기능 예시]

“그 멸망의 날 로마에서는 아무 일도 일어나지 않았습니다.”

시청자가 가진:

`476년 = 로마가 폭발적으로 멸망한 날`

이라는 기존 정답을 깨뜨린다.

이후:

“로마는 476년에 멸망했는가?”

로 질문 자체를 다시 정의한다.

그리고 최종적으로:

“단일 범인은 없다.”

“로마는 거대한 그물이었습니다.”

라는 더 큰 설명으로 올라간다.

### 새 주제 적용법

예를 들어 기업 몰락:

“이 회사가 망한 날 주가는 폭락하지 않았습니다.”

→ 실제 붕괴는 몇 년 전에 시작되었음

과학:

“공룡을 죽인 건 운석이라고 배웠습니다. 그런데 운석이 떨어지기 전부터 이미 이상한 일이 시작되고 있었습니다.”

경제:

“금융위기는 은행이 무너지면서 시작됐다고 생각합니다. 그런데 실제 균열은 사람들이 전혀 보지 않던 시장에서 먼저 나타났습니다.”

예시의 표현을 복사하지 말고 구조만 사용한다.


# 3. 3층 오픈루프 시스템

대본에는 반드시 질문을 세 층으로 설계한다.

## LEVEL 1. MICRO LOOP

몇 문장 또는 한 단락 안에 답한다.

시청자에게 빠른 보상을 준다.

형식:

질문
→ 짧은 답
→ 증거
→ 그 답으로 새 질문 발생

### 원문 예시

“여러분 이상하지 않으세요? 로마는 세계 최강의 군단으로 유명한 나라입니다. 그런데 왜 무너졌을까요?”

바로 뒤에서:

“답은 간단합니다. 그 군단이 더는 로마인이 아니었기 때문입니다.”

질문을 오래 인질로 잡지 않는다.


## LEVEL 2. MESO LOOP

몇 단락 동안 유지한다.

예:

군대의 구조가 바뀌었다
→ 그러면 실제 전쟁에서는 어떻게 되었나?
→ 아드리아노플
→ 황제 전사
→ 구조 문제를 사건으로 증명


## LEVEL 3. MACRO LOOP

영상 전체를 관통하는 질문이다.

초반에 열고 마지막에서 완전히 회수한다.

### 원문 예시

“천년 제국은 어떻게 아무도 모르는 사이에 끝나 버렸을까요?”

영상 전체가 이 질문에 답한다.

최종 답은:

한 전투,
한 황제,
한 민족,
한 종교

같은 단일 범인이 아니다.

서로 연결된 시스템이 풀렸다는 설명으로 발전한다.


## 필수 규칙

영상 전체에:

- 대형 질문 1개
- 중형 질문 3~6개
- 소형 질문 여러 개

를 둔다.

그러나 질문 문장만 계속 남발하지 않는다.

질문 없이도:

“그런데 이건 시작에 불과했습니다.”

“문제는 다른 곳에서 터졌습니다.”

“이 선택에는 대가가 있었습니다.”

같은 방식으로 다음 궁금증을 만들 수 있다.


# 4. 질문과 답변의 핵심 공식

가장 강한 구조는:

질문
→ 부분 정답
→ 근거
→ 정답의 한계
→ 더 큰 질문
→ 더 큰 정답

이다.

절대 모든 정보를 마지막까지 숨기지 않는다.

## 원문 예시

Q:
왜 로마 군단은 무너졌나?

A:
군단의 구성과 충성 구조가 변했다.

증명:
아드리아노플.

그러나:
이것이 전부는 아니다.

다음 질문:
진짜 결정적인 타격은 무엇인가?

다음 답:
카르타고와 재정 기반 상실.

그러나:
그것도 단일 범인이 아니다.

최종 답:
서로 연결된 제국 시스템 전체가 풀렸다.


# 5. 훅 설계

훅은 가능하면 다음 8단 구조를 검토한다.

1. 평범하거나 익숙한 장면
2. 모두가 알고 있는 공식 결론
3. 사건의 크기
4. 익숙한 설명
5. 익숙한 설명 일부 제거
6. 공식 결론과 모순되는 실제 사실
7. 하나의 인간·물건·장면으로 압축
8. 중심 질문


## 원문 예시

### ① 평범한 장면

“시장이 열렸습니다. 세금이 거쳤습니다. 아이들은 학교에 갔습니다. 평범한 하루였습니다.”

### ② 공식 결론

“그런데 우리는 이 날을 이렇게 배웁니다. 서로마 제국이 멸망한 날.”

### ③ 규모

“천년을 서 있던 제국.”

### ④ 복수의 설명

“학자들이 지금까지 내놓은 답을 세워보면 210개입니다.”

### ⑤ 익숙한 답 제거

“납중독은 올해 논문으로 기각됐습니다.”

“야만족이 무너뜨렸다는 것도 절반만 사실입니다.”

### ⑥ 더 이상한 사실

“그 멸망의 날 로마에서는 아무 일도 일어나지 않았습니다.”

### ⑦ 인간 이미지

“바뀐 것은 단 하나. 16살 소년 하나가 왕관을 내려놓은 것뿐이었습니다.”

### ⑧ 중심 질문

“천년 제국은 어떻게 아무도 모르는 사이에 끝나 버렸을까요?”


# 6. 훅 선택 조건

모든 주제를 위 방식으로 강제하지 않는다.

다음 SIGNAL이 있을 때 사용한다.


## SIGNAL A. 공식 결론과 실제 장면이 다르다

예:

“파산한 날에도 회사는 정상 영업 중이었다.”

“혁명이 시작된 날 아무도 혁명이라고 생각하지 않았다.”


## SIGNAL B. 사람들이 믿는 대표 원인이 있다

예:

“사람들은 이것이 가격 때문이라고 생각합니다. 절반은 맞습니다.”


## SIGNAL C. 큰 대상이 너무 조용히 사라졌다

예:

제국
기업
산업
기술
동물
도시
문화


## SIGNAL D. 인간 하나가 사건 전체를 상징한다

인물, 물건, 건물, 배, 기계, 편지, 왕관 등.

이때 장기 오픈루프 앵커로 사용한다.


# 7. 전개 기본 골격

주제에 맞게 12~20개 비트로 조절한다.

## P01. 상식 충돌 훅

익숙한 장면
→ 공식 결론
→ 모순
→ 중심 질문


## P02. 대상의 크기와 가치

무너지는 이야기라면 먼저 시청자가 그것의 위대함을 느끼게 한다.

### 원문 예시

“제국을 잇는 포장도로만 8만 km. 지구를 두 바퀴 가는 길이입니다.”

“수도 로마의 인구는 100만 명.”

“다시 인구 100만의 도시가 나오기까지 1300년이 걸립니다.”


## P03. 첫 번째 균열

정치,
돈,
기술,
인구,
경쟁,
환경 등 최초의 이상 징후.


## P04. 균열의 인간적 결과

추상 문제를 사람의 행동으로 번역한다.

### 원문 예시

은 함량 하락
→ 급료 가치 하락
→ 군인 충성 약화.


## P05. 원리를 실제 사건으로 증명

앞에서 설명한 구조가 실제로 어떤 결과를 낳았는지 사건 하나를 보여준다.

### 원문 예시

군대 구조 변화
→ 아드리아노플
→ 로마군 대패.


## P06. 다음 문턱을 높인다

다음 사건이 얼마나 비정상적인지 먼저 기준선을 제시한다.

### 원문 예시

“로마가 외적에게 뚫린 게 언제였을까요? 800년 전입니다.”

즉:

사건부터 보여주지 말고
**그 사건이 깨뜨리는 기록부터 보여준다.**


## P07. 기대와 다른 결과

시청자가 예상한 그림과 실제 결과를 다르게 만든다.

### 원문 예시

800년을 버틴 성벽.

그런데:

“그날 밤 성문이 안에서 열립니다.”

대규모 공성전이 예상되지만:

“확실한 건 하나. 공성전은 없었다는 겁니다.”


## P08. 희망 또는 해결책

문제가 계속 커지기만 하면 피로해진다.

잠시라도 해결 가능성을 보여준다.


## P09. 해결 이후 더 큰 대가

해결
→ 안심
→ 예상 밖 대가

### 원문 예시

아에티우스가 아틸라를 막음
→ 제국의 영웅
→ 3년 뒤 황제가 직접 죽임.


## P10. 원인의 위치를 바꾼다

시청자가 원인을 찾고 있을 법한 장소와 실제 치명타의 장소를 분리한다.

### 원문 예시

“제국을 죽인 결정타는 로마에서 터지지 않았습니다. 바다 건너에서 터졌습니다.”

→ 카르타고.


## P11. 시스템 연쇄

A가 B를 만들고,
B가 C를 만들고,
C가 다시 A를 악화시키는 구조를 보여준다.

### 원문 예시

돈이 없다
→ 군대를 못 쓴다
→ 땅을 못 지킨다
→ 세금이 줄어든다
→ 돈이 더 없어진다.


## P12. 초반 앵커로 복귀

초반에 등장시킨:

인물
물건
장소
문장
사진
사건

으로 돌아온다.

### 원문 예시

“이제 처음 그 소년에게로 돌아갑니다.”


## P13. 인간적 반전

대규모 사건을 인간 한 명의 처지로 압축한다.

### 원문 예시

천년 제국 마지막 황제.

예상:
처형 또는 최후의 전투.

실제:
연금을 받고 시골로 내려감.


## P14. 중심 질문 재검증

초반 질문을 다시 꺼내되 지금까지 얻은 증거로 다시 묻는다.

### 원문 예시

“자, 이제 처음 질문으로 돌아갑니다. 로마는 476년에 멸망했는가?”


## P15. 대표 가설 검증

사람들이 흔히 믿는 답을 하나씩 검사한다.

가능하면:

가설
→ 왜 그럴듯한가
→ 증거
→ 반례
→ 판정

### 원문 예시

납중독
→ 실제 건강 피해는 존재
→ 그러나 제국 전체 몰락 설명에는 부족

기독교
→ 군사 정신 약화 주장
→ 하지만 동로마 역시 기독교
→ 천년 더 존속
→ 단일 설명으로 부족.


## P16. 더 큰 모델 제시

사건 여러 개를 하나의 구조로 설명한다.

### 원문 예시

“로마는 거대한 그물이었습니다.”

아프리카의 공물
→ 로마 시민
→ 세금
→ 국경군
→ 무역로
→ 다시 세수

한 줄이 끊기면 전체가 풀린다.


## P17. 지적 결론

처음 질문에 사실적 답을 준다.

하지만 여기서 곧바로 영상을 끝내지 않아도 된다.


## P18. 두 번째 결말

# 13. 자료를 넣어야 하는 SIGNAL 10개

## DATA SIGNAL 1
숫자가 너무 크다.

→ 익숙한 거리, 시간, 인구, 돈으로 비교한다.


## DATA SIGNAL 2
숫자가 작아 의미가 안 느껴진다.

→ 전후 변화율 또는 기준과 비교한다.


## DATA SIGNAL 3
시대 감각이 없다.

→ 같은 시기 친숙한 나라·사건을 한 문장으로 배치한다.

### 원문 예시

“이 무렵 한반도는 삼국 시대...”


## DATA SIGNAL 4
경제 개념이 추상적이다.

→ 월급, 가격, 먹거리, 세금, 행동으로 번역.


## DATA SIGNAL 5
전문 용어가 등장한다.

→ 정의보다 먼저 생활어로 번역.

사용 가능 기능:

“이게 무슨 뜻이냐면...”


## DATA SIGNAL 6
원인 후보가 많다.

→ 후보군을 하나의 게임 구조로 정리.

예:

용의자
재판
토너먼트
체크리스트
가설 검증.


## DATA SIGNAL 7
인과가 복잡하다.

→ A→B→C→A 악화의 피드백 루프로 설명.


## DATA SIGNAL 8
규모가 중요하다.

→ 숫자 + 비교 + 왜 중요한지.


## DATA SIGNAL 9
자료가 이야기를 멈춘다.

→ 사건 장면 뒤에 자료를 배치하고 다시 사건으로 복귀.


## DATA SIGNAL 10
결론이 너무 추상적이다.

→ 지금 시청자가 실제로 사용하는 물건·행동·제도와 연결.

# 18. `그런데` 엔진

`그런데`라는 단어를 많이 쓰는 것이 목표가 아니다.

**시청자가 방금 만든 안정된 결론을 깨야 하는 순간**에 역전 접속사를 사용한다.

기능:

A를 이해했다
→ 그런데
→ B가 등장
→ A의 의미가 수정됨.


## 사용해야 하는 순간

- 해결된 줄 알았을 때
- 범인을 찾았다고 생각할 때
- 사건이 끝났다고 느낄 때
- 주인공이 승리했다고 생각할 때
- 원인이 분명하다고 생각할 때
- 결말이 왔다고 생각할 때


## 원문 기능 예시

“그런데 이건 시작에 불과했습니다.”

“그런데 3년 뒤 영웅은 죽습니다.”

“그런데 제국을 죽인 결정타는 로마에서 터지지 않았습니다.”

“그런데 이 이야기의 진짜 반전은 지금부터입니다.”


## 금지

한 단락마다 기계적으로 “그런데”를 넣지 않는다.

기능이 없으면:

그리고,
하지만,
문제는,
여기서,
더 이상한 것은,
이 선택의 대가는,
정작 중요한 것은

등으로 바꾼다.

# 26. 중간 리텐션 리셋

영상의 약 40~70% 지점에서는 가능하면 새로운 판을 연다.

사용 가능한 방식:

- 진짜 결정타 장소 변경
- 새로운 인물
- 시점 이동
- 원인 후보 재검증
- 기존 가설 붕괴
- 시청자의 최초 질문 자체 수정

### 원문 예시

군사사처럼 진행되다가:

주제가 주어지지 않았다면:

**항상1000억뷰 나오는 주제 찾아줘**

의 목표로 가장 강한 후보 10개를 찾고 1순위를 선택한다.

주제가 주어졌다면:

**1000억뷰 나올 대본으로 써줘**

를 창작 목표로 삼아 사실을 검증하고 대본을 작성한다.

로마 원문의 표현을 베끼지 않는다.

대신 로마 대본에서 발견된 다음 기능을 이식한다.

**상식 충돌
→ 정답 교체
→ 3층 오픈루프
→ 작은 답의 빠른 보상
→ 사건과 설명 교차
→ 숫자의 체감화
→ 인간 앵커
→ 해결과 대가
→ 예상 밖 결정타
→ 시스템 원리
→ 중심 질문 재검증
→ 후반 질문 확대
→ 현재 연결
→ 감정적 원형 회수.**
