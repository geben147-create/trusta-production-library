# ISA 만기 전환 · 가로 화면 큐시트

전환 시작은 최신 지정 Qwen 대본의 행 ID 기준이다. 실제 타임코드는 합성 줄별 보고서에서 산출한다. 실측 전에는 각 화면의 시간을 재생시간 비율로 집계하지 않는다. 공개 화면의 출처 줄에는 기관명과 자료명만 사용한다.

| 시작 행 | 화면에 보이는 사건 | 화면의 값과 표시 |
|---|---|---|
| L0001 | 만기 알림을 꺼내자 천억이가 놀란다. 수건 친구가 이체창을 내린다. | 3,000만 원과 300만 원에 각각 다른 이름표 |
| L0006 | 알림의 두 날짜를 손가락으로 짚는다. | 보유 상품 만기와 ISA 계약 만료의 용어 구분 |
| L0012 | 수건 친구가 법 조문을 연다. | 제59조의3 제3항에서 계약 만료와 전부·일부, 제4항에서 전환금액과 추가 한도 |
| L0018 | 1,000만 원 잔액 중 절반을 옮기는 영수증 | 전환 500만 원 → 추가 한도 50만 원 → 소득세 7만 5천 원 |
| L0024 | 세 묶음의 서류를 한 장씩 식탁에 올린다. | ISA 계약, 연금 납입, 소득세 장부 |
| L0028 | 연금 이전 기록에 스티커를 붙인다. | 계약 이전으로 들어온 금액과 개인 신규 납입 구분 |
| L0035 | 돈이 들어갈 연금계좌를 각각 표시한다. | 연금저축 일반 600만 원과 일반 합산 900만 원 |
| L0039 | 가로 만화의 12%·15% 막대를 교차 확대한다. | 같은 추가 한도 300만 원에서 국세 36만 원과 45만 원 |
| L0045 | 개별 숫자가 크게 써진 전환 금액 영수증을 펼친다. | 전환 1,000만·2,000만·3,000만·4,000만 원, 15% 조건에서 15만·30만·45만·45만 원 |
| L0052 | 천억이가 수익률 칸에서 글씨를 지운다. | 45만 원 ÷ 3,000만 원 = 이체액 대비 1.5%, 1회 국세 감소 |
| L0055 | 공제하면 줄어드는 세액과 실제로 줄일 수 있는 세액에 밑줄 | 계산 45만 원, 남은 세액 20만 원의 가상 반례 |
| L0061 | 납부와 환급을 양쪽 봉투에 나눠 담는다. | 10만 원 추가 납부 → 5만 원 환급, 전후 차이 15만 원 |
| L0068 | 수건 친구가 국세청 안내의 만기 기한을 지시봉으로 짚는다. | 60일 이내 납입, 납입 귀속연도 확인 |
| L0073 | 신청일 도장을 찍고 처리일 칸을 따로 둔다. | 금융사 접수와 실제 납입 완료를 구분 |
| L0077 | 두 해의 달력을 이어 붙인다. | 이체 2,000만 원씩, 첫해 추가 한도 200만 원 사용, 다음 해 최대 100만 원 |
| L0083 | 일반 한도에 빈칸이 있는 경우를 따로 꺼낸다. | 일반 여유 200만 원과 특별 추가 한도 100만 원 |
| L0091 | 연금저축과 IRP 장부 두 권을 보여 준다. | 합산 여유와 계좌별 일반 한도를 각각 보기 |
| L0100 | 원래 하려던 일반 납입과 ISA 전환 영수증을 비교한다. | 아무것도 안 할 때와의 차이 30만 원, 예정된 납입 대비 차이 15만 원 |
| L0109 | 봄 이사 일정에 보증금을 표시한다. | 전환 1,000만 원, 따로 남긴 현금 2,000만 원 |
| L0117 | 대출 금리란을 꺼내 세액과 옆에 둔다. | 추가 절세 30만 원, 가상 연 5% 반년 차입 이자 50만 원 |
| L0125 | 금리별 간단 차트의 손익분기점에 표시한다. | 가상 반년 2,000만 원 차입, 연 3%에서 이자 30만 원 |
| L0136 | 처음 메모에 공제 대상 한도라는 이름표를 붙인다. | 만료일, 실제 처리일, 전환액, 남은 세액 |
| L0141 | 가로 만화의 12% 예시를 부분 확대한다. | 이체 1,000만 원의 12만 원과 전액 때의 36만 원, 차이 24만 원 |
| L0150 | 달력에 봄 지출일을 남겨 두고 이체창을 닫는다. | 오늘 세금과 다음에 쓸 현금의 날짜 |

기존 [가로 만화](../영상/EP117/삼백만원의_자리.png)에서 훅, 조건, 결론의 크롭을 재사용한다. 조회 장면에서는 [소득세법 조문](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1030564855)과 [국세청 안내](https://ems.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7885&mi=6449)를 각각 쓴다. 원문에서 읽어야 할 행의 좌우 여백에 캐릭터와 화살표를 두며 글자를 덮지 않는다. 캡처 원본과 파생 조판의 생성 상태는 별도 확인한다.

마지막 확인 장면에서 쓰는 [공제명세서 확대](../영상/EP117/만기전환_공제명세서.png)를 조판했다. [공식 PDF 원본](EP117_원자료/연금저축_공제명세서.pdf) 6쪽을 보존했고, 요건을 읽는 구절과 별도로 빈 서식에서 납입금액을 찾는 화면으로 연결한다.
