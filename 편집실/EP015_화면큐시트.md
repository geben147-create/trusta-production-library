# 은퇴 후 배당과 남은 돈 화면 큐시트

1920×1080. 실제 지정 Qwen 음성이 준비되면 타이밍을 확정한다.

| 장면 | 화면 |
|---|---|
| 관리비 고지서 | 천억이는 배당 앱을, 수건 친구는 고지서 납부일을 짚는다. |
| 서로 다른 입구 | 두 추종 지수의 정식 이름을 띄운다. 원화 생활비와 달러 분배는 달력에서 분리한다. |
| 표시율 반전 | 가로 만화의 왼쪽을 확대한다. 천억이가 4달러는 그대로인 두 행을 가리킨다. |
| 남은 돈 | 수건 친구가 1년 장부의 100달러와 84달러를 비교한다. 가상 주식 80달러와 현금 4달러를 구분한다. |
| 원문과 달력 | 제품별 배당·분배 원문 캡처를 확보하면 좌당 지급액과 지급일에 붉은 원을 넣고 천억이가 가리킨다. |

가상 1주 1년, 달러, 배당 재투자 없음, 세금과 거래·환전 비용 0. 특정 ETF의 실측 배당률로 표시하지 않는다.
