# 은퇴 생활비 국채 ETF 비교 화면 큐시트

유튜브 가로 1920×1080. 장면은 원고의 여덟 단계에 대응하며, 시간은 지정 Qwen 음성 확정 뒤 맞춘다. 이번 문서는 제작 큐다.

| 화면 | 장면과 편집 | 숫자와 문구 |
|---|---|---|
| 치과 예약 | 식탁을 가로로 길게 잡는다. 수건 친구가 달력을 펼치고 천억이가 치과 고지서를 내민다. 손과 고지서를 한 번 확대한다. | “석 달 뒤, 이 돈을 써야 해.” |
| 만기 범위 | 두 사람 사이의 서류 띠를 길이가 다른 시간축으로 연결한다. 천억이가 손끝으로 각 축의 시작과 끝을 짚는다. | SGOV 0~3개월, IEF 7~10년. ‘편입 채권의 만기’는 옅은 레몬색. |
| 5년 차트 | 천억이와 수건 친구 사이에 두 개의 반투명 유리 막대를 세운다. 0달러 공통선에서 정면으로 읽는다. 막대 윗면과 오른쪽 측면만 가볍게 보이고 진한 모서리와 접지 그림자를 넣는다. 숫자 두 칸은 막대 위 같은 높이에 고정한다. | 2021년 초~2025년 말 · 미화 1만 달러씩 · SGOV 11,722.01달러 · IEF 9,121.93달러. NAV 총수익률 재투자 가상 잔액. |
| 잔금 봉투 | 2022년 화면에는 수건 친구가 9,000달러 고지서를 들고, 입을 크게 벌린 천억이가 빈 봉투를 보여 준다. | 별도 2022년 1년 예시. SGOV 1,158달러 남음, IEF **523달러 부족**. |
| 순서가 바뀐 달력 | 같은 투입금의 2025년 한 해 카드가 기존 카드 위에 올라온다. 색상과 막대 종류는 유지하고 기간 문구를 진한 무광 칸에 둔다. | 2025년 별도 1년 예시. 10,424달러 대 10,806달러. IEF가 382달러 앞섬. |
| 운용사 원문 | 운용사 페이지에서 상품 목표와 달력연도 총수익률 행 확대. 빨간 원은 행 제목 바깥으로, 천억이 지시봉은 글자 바깥에 둔다. 캡처를 확보한 경우 사용한다. | 출처에는 기관과 자료 이름을 표기. 관측 연도는 값 옆에 유지. |
| 환전 계산 | 화면 가운데 고지서와 원화 계산기, 왼쪽 하단에 지시봉을 든 천억이. 환율 숫자 두 개는 한 줄씩 나타난다. | 가상 환율 1,400원→1,300원. 달러 잔액 1만 달러 고정 시 1,400만 원→1,300만 원. |
| 납부일 회수 | 처음 달력에 손으로 날짜·금액·통화를 함께 적는다. 옆에서 두 인물이 고지서를 달력에 꽂는다. | “내가 돈을 꺼낼 날은 언제?” |

금액과 티커는 페이퍼로지 또는 여기어때 잘난체 고딕 실파일 확인 뒤 적용한다. 숫자는 불투명한 칸에 넣고 축소 화면에서 겹침을 검사한다. 최종 PNG와 기존 세로 카드 연결은 확인 후 기록한다.
