# 마지막 월급이 바꾸는 두 장부 화면 큐시트

1920×1080. 지정 Qwen 음성에 맞춰 길이를 확정한다.

| 장면 | 화면 |
|---|---|
| 퇴직 희망일 | 천억이가 날짜에 동그라미를 치고 수건 친구가 첫 투자계좌 출금일을 찾는다. |
| 첫해 자금 방향 | 가로 만화의 두 말풍선을 이어 첫해 +1,000만 원과 −1,000만 원을 각각 보여준다. |
| 하락과 상승이 먼저일 때 | 두 막대 묶음을 번갈아 강조한다. 수건 친구가 같은 시장에서도 자금 흐름이 다름을 짚는다. |
| 입출금이 없다면 | 천억이가 첫해 자금 이동을 0원으로 바꾼다. 가상 2년 뒤 9,000만 원을 보여준다. |
| 내 달력 | 두 사람이 다음 급여, 확정 연금과 첫 투자계좌 출금 필요일을 같은 달력에 놓는다. |

원화 가상 사례. 두 해 연말 수익 반영 후 자금 이동. 세금·비용·물가 제외, 분배금 재투자.
