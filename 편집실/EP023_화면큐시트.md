# IRP에 현금 350만 원, ETF 주문 여력 50만 원

가로 1920×1080. 지정 Qwen 내레이션 실측 후 장면 경계를 시간으로 기록한다.

| 장면 | 화면과 인물 | 확인할 숫자 |
|---|---|---|
| 주문이 멈춘 날 | 휴대폰을 쥔 천억이의 손과 놀란 표정. 수건 친구가 옆에서 계좌 이름을 짚는다. | 현금 350만 원. |
| 검색 창 두 개 | 두 계좌 이름과 ETF 칸을 나란히 잡는다. 두 인물이 주문 가능 상품과 분류를 다른 색에 표시한다. | 매수 가능 여부와 일반 위험자산 분류. |
| 숫자를 빼는 순간 | 완성 가로 만화의 공통 0축을 유지한다. 색 막대의 두 구간을 순서대로 읽는다. | 1,000만 원 × 70% = 700만 원. 기존 650만 원을 빼면 여력 50만 원. |
| 현금 450만 원 두 장 | 같은 현금 잔액의 영수증 두 장을 손으로 분리한다. 왼쪽은 외부 입금, 오른쪽은 내부 매도다. | 납입 뒤 여력 120만 원, 기존 위험자산 매도 뒤 150만 원. |
| 주문 단위 | 천억이가 주식표 네 장을 밀어 둔다. 주당 가상 가격이 바뀔 때 한 장을 뒤로 뺀다. | 12만 원이면 4주, 13만 원이면 3주. 여력 50만 원 고정. |
| 금융회사 자료 | 실제 설명서 캡처가 확보되면 투자위험한도 문장을 확대한다. 두 인물 중 하나는 숫자 밖에서 지시봉을 든다. | 출처 미래에셋증권 · 개인형 IRP 설명서. |
| 현금과 인출 | 수건 친구가 계좌 안 현금과 계좌 밖으로 송금하는 현금의 방향을 따로 그린다. | 주문 여력과 부분 인출 조건을 따로 읽기. |
| 폰을 다시 든다 | 처음 화면으로 돌아와 천억이가 같은 코드를 두 계좌에서 조회한다. | 매수 가능 여부 · 분류 · 주문 여력. |
