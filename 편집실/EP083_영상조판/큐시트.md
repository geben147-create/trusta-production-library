# 눌림목 비교 화면 큐시트

지정 합성 뒤 실제 타임코드를 연결한다.

- L0001–L0012 장바구니에 같은 할인표가 붙었다
- L0013–L0022 할인과 관찰 후보를 구분한다
- L0023–L0032 같은 기간을 쓰고 오늘 값을 빼둔다
- L0033–L0045 두 장을 넘겨 본다
- L0046–L0056 먼저 탈락한 종목이 웃는다
- L0057–L0069 기다리면 덜 잃을 수도 있고 기회를 놓칠 수도 있다
- L0070–L0083 장부에는 다음 날 반등하지 않은 후보도 들어간다
- L0084–L0096 할인 딱지 옆에 오늘 밤의 판정을 적는다
