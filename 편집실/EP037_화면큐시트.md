# 퇴직금 일부의 세 달 화면 큐시트

1920×1080. 지정 Qwen 음성 확보 후 화면 길이를 확정한다.

| 장면 | 화면 |
|---|---|
| 첫날 같은 통장 | 천억이와 수건 친구가 두 장부에 원화 120만 원씩 적는다. |
| 장이 내려간 달 | 기존 세로 카드와 비교할 때는 원금 300만 원의 별도 예임을 표시한다. 가로 만화에는 120만 원 사례를 사용한다. |
| 나눠서 더 산 주식 | 가로 만화에서 120만 원과 130만 원을 짚으며 천억이의 표정으로 전환한다. |
| 계속 오르는 달력 | 수건 친구가 192만 원과 155만 2,000원을 비교한다. 두 경로의 종료 조건은 같은 방식으로 읽는다. |
| 내 생활비 달력 | 천억이가 매수 후 남은 현금과 다음 달 쓸 금액을 나란히 놓는다. |

세 번의 가상 원화 매수, 마지막 매수 직후 평가. 대기 이자·분배·세금·비용 0, 재투자 없음.
