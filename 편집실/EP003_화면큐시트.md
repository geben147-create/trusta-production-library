# 같은 지수와 다른 권리 화면 큐시트

가로 1920×1080. 시간은 지정 Qwen 음성이 완성된 뒤 맞춘다.

| 장면 | 화면 | 남길 말과 값 |
|---|---|---|
| 마지막 글자 | 주문 화면에서 ETF와 ETN의 끝 글자만 확대한다. 천억이가 옆에서 놀란다. | “지수가 같으면 상품도 같을까?” |
| 권리 세 장 | 수건 친구가 주식, ETF, ETN의 카드 세 장을 옆으로 펼친다. | 기업 지분 · 펀드 지분 · 발행사의 채무증권. |
| 주문 창구와 발행인 | 서로 다른 가상 증권사 이름을 봉투 두 장에 적고 다른 화살표로 잇는다. | 주문 받는 곳과 지급 약속 주체를 확인. |
| 지표와 가상 매도가 | 가로 정보 만화의 지표가치와 매도 금액을 두 번 나누어 확대한다. | 105만 원의 94%에 팔면 98만 7,000원. |
| 다른 예외 | 천억이가 내려간 지표를 짚고 수건 친구가 다른 서류의 지급 조건을 읽는다. | 지표 하락과 지급 불이행을 구분. |
| KIND 공시 | 실제 자료 화면이 확보되면 발행인·기초지수·만기 항목을 순차 확대한다. 빨간 원과 지시봉은 원문을 가리지 않는다. | 출처 한국거래소 KIND · ETN 공시 사례. |
| 먼저 산 값 | 주문 영수증 옆에 약정대로 받은 가상 지급액을 놓는다. | 10,500원 매수, 10,300원 수령이면 200원 손실. |
| 첫 페이지로 돌아감 | 천억이가 처음 고른 두 상품의 발행 또는 운용 주체를 읽는다. | 지수 · 관리 주체 · 매도 또는 상환 시점. |

가로 만화는 원화 가상 예시로 표시한다. 공시의 실제 상품별 지급 조건을 가상 수치와 혼합하지 않는다.
