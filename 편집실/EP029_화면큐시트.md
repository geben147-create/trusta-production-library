# 마지막 출근날의 401(k) 화면 큐시트

1920×1080. 지정 Qwen 음성 확보 후 화면 시간을 맞춘다.

| 장면 | 화면 |
|---|---|
| 마지막 출근 | 천억이가 가상 퇴직 안내서와 계좌 잔액을 책상에 놓는다. |
| 두 납입자 | 수건 친구가 직원 2,000달러와 회사 1,000달러를 다른 색으로 밑줄 친다. |
| 귀속 장부 | 가로 만화에서 회사분 400달러와 1,000달러, 각 합계 2,400달러와 3,000달러를 번갈아 본다. |
| 실제 지급 확인 | 천억이가 퇴직 날짜·귀속·지급 세 칸을 따로 표시한다. |
| IRS 원문 | 추후 원문 캡처에 직원과 회사의 귀속 기준을 동그라미 치고 수건 친구가 가리킨다. |

가상 달러 1년. 특정 플랜의 실제 귀속률이나 세후 지급액으로 표시하지 않는다.
