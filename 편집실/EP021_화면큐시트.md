# 목요일 오전 열 시 · 화면 큐시트

기준 음성은 eSpeak NG ko 175, 재생은 1.2배속이다. 아래 구간은 같은 조건에서 장면별로 합성해 초 단위로 반올림했다. 실제 성우가 바뀌면 재측정한다.

|재생 구간|하몬 단계|다음에 확인할 질문|화면 전환|
|---|---|---|---|
|00:00–01:18|일상|계약서와 휴대폰의 숫자가 다르다|생성한 16:9 열쇠 사진 전체 → 열쇠 고리 → 휴대폰의 손. 같은 장면에서 첫 질문만 자막으로 띄운다.|
|01:18–03:15|필요|남길 돈과 송금할 돈에 다른 날짜가 있다|카드의 일반계좌 행과 달력 날짜를 교차한다. 50·30·20만 원은 필요 시점이 달라지는 순간만 순서대로 노출한다.|
|03:15–05:45|진입|일반계좌에서 매도와 출금은 다른 시각이다|주문 → 체결 → 결제 → 출금 네 단어를 한 번에 하나씩 밝힌다. 하락 가정에서 500만→400만으로 숫자를 교체한다.|
|05:45–09:01|탐색|세금과 인출을 한 장부에서 분리한다|기존 9:16 카드의 ISA 행 확대. 적격 순소득 300만→과세 100만→세액 9.9만 원을 칸마다 보여 준다.|
|09:01–11:06|발견|가격이 그대로여도 똑같은 부족액이 생긴다|자체 16:9 그래프의 500만·400만 막대를 차례로 펼친다. 차액 100만 원에만 강조색을 쓴다.|
|11:06–15:38|대가|공제를 받는 선택에는 출금 조건이 붙는다|카드의 연금저축·IRP 행을 번갈아 확대한다. 납입 재원과 수령 방법을 서로 다른 자막으로 둔다.|
|15:38–18:56|귀환|목요일의 세 봉투를 다시 계산한다|같은 그래프 구도를 재사용해 각 봉투의 현금과 평가액을 바꾼다. 숫자 설명을 마친 뒤 9:16 원본 전체와 Q&A로 돌아온다.|
|18:56–21:13|변화|현수가 수익률보다 먼저 출금 시각을 본다|도입의 열쇠 사진으로 복귀한다. 휴대폰을 향해 가던 손 위에 ‘언제 얼마를 보내야 하나요?’ 한 문장만 얹는다.|

가로 구도는 [도입 장면](../시각자료/EP021_목요일_열쇠.jpg)과 [검산 그래프](../시각자료/EP021_원금인출_부족액.png)를 쓴다. [계좌 4종 세로 원본](../그림/EP021.png)은 비율을 유지한 채 전체·행·핵심 수치 순으로 확대한다.

추가 생성 없이 숫자가 처음 등장할 때, 조건이 바뀔 때, 도입 질문으로 돌아올 때 컷을 전환한다. 법 조문을 읽는 동안에는 글씨를 읽을 시간을 둔다.
