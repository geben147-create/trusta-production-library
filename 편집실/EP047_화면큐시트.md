# 분배금 10만 원의 한 달 화면 큐시트

1920×1080. 지정 Qwen 음성 확보 후 장면 시간을 맞춘다.

| 장면 | 화면 |
|---|---|
| 월요일 입금 | 수건 친구가 식비 봉투를 들고 천억이가 재매수 버튼을 가리킨다. |
| 사는 가격 | 9,000원과 10만 원을 같은 장부에 놓고 추가 매수 좌수를 적는다. |
| 두 월말 | 가로 만화의 두 묶음을 차례로 강조한다. 1만 원 차이 방향이 뒤집힐 때 천억이 표정을 살린다. |
| 한 주 단위 | 기존 세로 카드는 35,000원과 15,000원의 별도 예시로 표시하고 수건 친구가 잔돈을 짚는다. |
| 내 계좌 | 입금액, 매수일, 실제 체결가, 식비 날짜를 놓고 필요한 현금부터 확인한다. |

가상 원화, 한 달, 세금·매매비용·현금 이자 0. 소수점 재투자를 허용한 경우와 정수 매수를 분리한다.
