# ETF 청산 알림 화면 큐시트

1920×1080. 지정 Qwen 음성이 준비되면 길이를 맞춘다.

| 장면 | 화면 |
|---|---|
| 관리비와 거래 종료 알림 | 천억이가 휴대전화와 고지서를 펼치고 수건 친구가 날짜 칸을 두 개 만든다. |
| 실제 두 날짜 | 가로 만화의 과거 사례에서 마지막 정규장과 청산 예상일을 차례로 확대한다. |
| 별도 가상 영수증 | 천억이가 188달러를, 수건 친구가 190달러와 185달러를 각각 짚는다. |
| 계좌 입금일 | 중개사 입금 확인일과 생활비 납부일을 달력 아래에 다른 색으로 표시한다. |
| 실제 공지 | 별도 확보한 원문 위에서 펀드명·날짜·현금 분배 문구에 빨간 표시를 넣는다. |

공식 공지의 예정 일정과 별도 가상 달러 계산을 구분한다.
