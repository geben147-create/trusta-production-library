# 좌당 분배금과 같은 투자 예산 화면 큐시트

1920×1080. 지정 Qwen 음성에 맞춰 길이를 확정한다.

| 장면 | 화면 |
|---|---|
| 고지서와 공시 | 수건 친구가 좌당 292원과 60원을 짚고 천억이가 예산 봉투를 내민다. |
| 같은 수량 | 가로 만화의 왼쪽 2,920원과 600원을 확대한다. |
| 같은 100만 원 | 천억이가 가상 매수가를 제시하고 오른쪽 막대에서 2,920원과 12,000원을 보여준다. |
| 공식 원문 | 원문 캡처를 확보하면 두 코드와 좌당 금액에 빨간 원을 넣고 수건 친구가 가리킨다. 기존 세로 카드는 주당 200원 가상 보조 예시다. |
| 생활비 달력 | 두 인물이 실제 지급일과 세후 입금액을 확인한다. |

한 회차 실제 좌당 공시와 가상 매수 조건을 구분한다. 재투자·비용·세금 제외.
