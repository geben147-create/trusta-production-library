# 일본 ETF 거래대금과 순설정 화면 큐시트

1920×1080. 지정 Qwen 음성에 맞춰 길이를 확정한다.

| 장면 | 화면 |
|---|---|
| 친구의 순위표 | 천억이가 가상 순위표를 보여 주고 수건 친구가 열의 이름을 먼저 짚는다. |
| 손을 바꾸는 100좌 | 두 인물이 같은 묶음을 세 번 옮긴다. 10만 엔씩 한 번만 집계한다. |
| 30만 엔과 0엔 | 가로 만화에서 파란 막대와 순설정 표시를 차례로 확대한다. |
| 반대 상황 | 수건 친구가 거래소 거래 없이 200좌를 새로 설정하는 가상 펀드 장부를 펼친다. |
| 원문 조회 | 일본거래소 캡처 확보 후 기간과 열 이름에 빨간 표시를 넣고 천억이가 가리킨다. |

가상 엔화 하루 사례. NISA의 편입 조건은 일본 금융청 자료에서 별도로 확인한다.
