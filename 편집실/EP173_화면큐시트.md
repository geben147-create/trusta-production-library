# 은퇴 후 집을 팔기 전 대출 갈아타기 화면 큐시트

1920×1080 가로 영상용. 음성 실측을 받은 뒤 구간 시작 시간을 연결한다. 수치는 원화 가상 사례다.

| 원고 장면 | 영상 컷 | 화면 정보 |
|---|---|---|
| 매물 계약서 | 수건 친구가 계약서 위에 열쇠를 올린다. 천억이는 금리 알림을 든 채 입을 크게 벌린다. | “연 5%에서 4%로!” |
| 처음 나가는 돈 | 열쇠 아래에 두 장의 견적을 놓는다. 수건 친구 손끝이 기존 대출 비용을 짚는다. | 갈아타는 날 60만 원. |
| 같은 원금 | 잔액 1억 원을 한 번만 크게 쓰고 금리 두 줄 옆에 같은 종료일을 강조한다. | 원화 잔액 1억 원 고정. 연 5% 대 연 4%. |
| 6개월과 9개월 | 완성 가로 만화의 막대 영역을 확대한 뒤 두 사람의 표정을 보여 준다. 6개월의 왼쪽 막대, 9개월의 오른쪽 막대 순서로 가리킨다. | 6개월 순절감 −10만 원. 9개월 +15만 원. 양쪽 종료일 비용 없음 가정. |
| 우대금리 조건 | 열쇠를 옆으로 밀고 새 견적에 표시된 4.5%에 붉은 원을 그린다. | 연 4.5%라면 12개월 순절감 −10만 원. |
| 5년과 10년 | 천억이가 종이 두 장을 분리해 왼편은 월 납부액, 오른편은 끝까지 낸 이자를 짚는다. | 5년 월 약 184만 원·총이자 약 1,050만 원, 10년 월 약 101만 원·총이자 약 2,149만 원. 두 안 모두 연 4%. |
| 금융위 근거 | 공식 자료의 이자와 중도상환수수료 비교 문장을 확대한다. 실제 캡처를 확보했다면 지시봉이 문장 바깥을 가리키게 배치한다. | 출처 금융위원회 · 대환대출 인프라와 비용 비교 안내. |
| 열쇠와 두 날짜 | 수건 친구가 열쇠를 넘기고 천억이는 달력에 갈아타는 날과 최종 상환일을 하나씩 적는다. | “같은 날까지 얼마를 내야 하지?” |

도입 만화는 시각자료의 기존 완성본을 사용한다. 9:16과 근거 캡처는 파일이 확보된 경우에만 가로 화면 안에 연결한다.
