# ETF 두 바구니와 내 영수증

기존 가로 만화 두 장은 1920×1080, 보조 만화는 1080×1350을 확인했다. 이번 편은 세로 보조 만화의 비율을 보존해 가운데 놓고 양옆에 두 캐릭터와 상황별 금액을 배치한다. 아래는 장면 순서다. 시간과 자막 위치는 지정 음성의 줄별 구간이 나온 뒤 확정한다.

| 원고 장면 | 보여 줄 자료와 화면 전환 | 캐릭터 동작 |
|---|---|---|
| 숫자 하나를 메모했다 | 기존 가로 만화의 두 ETF와 영수증을 먼저 보여 주고, 화면의 가중 겹침은 이 그림의 별도 사례에 해당함을 밝혀 준다. 장면이 본문의 첫 50% 예로 바뀌면 수치를 새 보드에 적는다. | 천억이가 50%를 영수증에 옮겨 쓰려다 펜을 멈춘다. |
| 종목 이름이 겹치는 개수를 센다 | X 카드가 두 바구니에 공통으로 있다는 장면에서 1/3과 1/2의 분모만 각각 옅은 레몬색으로 띄운다. 다음 컷에서 1/19와 40% 반례로 넘어간다. | 수건 친구가 먼저 합친 목록을 펼치고, 천억이가 A 목록의 끝을 가리킨다. |
| 종목별 작은 비중을 더한다 | 같은 X의 50%와 20%를 비교한 뒤 작은 비중 20%를 표시한다. 공통 이름 열 곳이 양쪽에서 각각 10%인 반례는 별도 화면에 둔다. | 천억이가 열 줄 전부에 칠했다가 수건 친구가 90% 한 줄을 지시봉으로 짚자 시그니처 표정으로 반응한다. |
| 내 영수증에서는 금액에 비중을 곱한다 | 기존 4:5 보조 만화의 A 50만 원과 B 50만 원, 10%와 14%로 계산한 12만 원을 따로 재생한다. 이어 본문 90만 원과 10만 원 예로 돌아갈 때 제목에 ‘새 가정’이라고 적는다. | 양쪽 여백에서 천억이가 곱셈 줄을, 수건 친구가 합계 금액을 가리킨다. |
| 친구와 계좌의 답이 달라졌다 | 기존 가로 만화 `같은ETF_다른노출.png`에서 투자 배분만 번갈아 확대한다. 47만 원과 23만 원은 같은 정면 0선으로 비교하고 값은 무광 라벨로 적는다. | 친구가 영수증 두 장을 나란히 놓는다. 천억이가 24만 원 차이를 표시한다. |
| 현금과 직접 보유를 더했다 | 분모가 100만 원에서 200만 원이 되는 X 예를 재생한다. 이어 SEC 비중을 적용한 별도 장면에서 직접 보유 여부에 따른 146,560원과 346,560원을 비교한다. | 수건 친구가 현금 영수증을 분모 칸에 끼우고 천억이가 직접 보유 영수증을 분자에도 얹는다. |
| 운용사 파일을 같은 날짜로 맞춘다 | `실제공시_겹침과노출.png`에서 공통 21/34, 가중 겹침 68.81%, 엔비디아 노출액을 차례로 강조한다. SEC 원문 화면에는 두 보고서의 같은 관측일과 동일 ISIN, 각 순자산 비중을 실제 원문으로 표시한다. 화면에서는 자료명만 출처에 적는다. | 수건 친구가 같은 ISIN 두 곳을 연결하고 천억이가 다른 비중 칸을 표시한다. |
| 계산기로 회사 하나를 다시 본다 | 노출액을 줄인 경우와 비율만 낮아진 경우를 나란히 놓는다. 마지막 영수증에는 ‘현재 평가액 × 종목 비중 + 직접 보유액’과 계좌 전체 평가액을 남긴다. | 천억이가 두 장의 영수증을 한 장부에 끼우고 친구에게 계산기를 건넨다. |

SEC 원본은 `FAQ01_원자료/SOXX.xml`과 `FAQ01_원자료/SMH.xml`에 보관했다. 두 파일의 확인 화면은 추후 실제 캡처 후 연결한다.
