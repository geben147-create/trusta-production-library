# 인버스 ETF 이틀 장부 화면 큐시트

1920×1080. 지정 Qwen 음성 확보 후 타이밍을 맞춘다.

| 장면 | 화면 |
|---|---|
| 생활비 전날 | 천억이가 계좌와 지수의 처음·끝을 적고 수건 친구가 ‘하루’에 밑줄을 긋는다. |
| 첫날과 둘째 날 | 가로 만화의 세 열을 시간 순서대로 강조한다. 지수와 원화 계좌를 별도 행으로 유지한다. |
| 제자리와 손실 | 둘째 날 지수 100과 잔액 981,818원을 차례로 확대하고 천억이의 시그니처 표정을 남긴다. |
| 다른 경로 | 수건 친구가 지수 100→90→100을 적고 다른 잔액을 짚는다. |
| 공식 설명서 | 원문 캡처 확보 후 기준 지수와 하루 목표를 동그라미 치고, 천억이가 자신의 계좌 옆에 놓는다. |

원화 100만 원 가상 이틀. 비용 전 일일 −1배를 정확히 달성하는 경우로, 실제 ETF 시세가 아니다.
