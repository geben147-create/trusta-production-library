# 분배금과 한 주 장부 화면 큐시트

가로 1920×1080. 합성 완료 후 지정 음성의 줄별 시간으로 구간을 맞춘다.

| 장면 | 화면 | 표시할 값 |
|---|---|---|
| 관리비가 나가는 날 | 천억이가 휴대폰을 급하게 들고, 수건 친구는 영수증에 찍힌 날짜를 펼친다. | “분배금이 있다는데 왜 통장은 그대로지?” |
| 가격의 이름 | 여백 왼쪽에 주당 순자산가치, 오른쪽에 매도가 두 칸을 둔다. 손가락이 각 숫자의 단위를 짚는다. | 같은 상품 · 같은 통화 · 같은 시점. |
| 가로 만화 확대 | 1만 원에서 9,800원으로 이동한 뒤, 별도 분배금 칸을 더한다. | 원화 1주 가상 사례. 9,800원 + 150원 = 9,950원. |
| 입금 전후 | 수건 친구가 은행 장부의 입금 예정 표시를 뒤로 옮긴다. | 100주 가정, 사흘 뒤 입금이면 오늘 7,000원 부족. 같은 날 먼저 입금되면 납부 뒤 8,000원 남음. |
| 한 주의 매도 영수증 | 천억이가 받는 분배금과 실제 매도가를 종이 두 장에서 각각 읽는다. | 매도가 9,760원 + 분배금 150원 = 9,910원. |
| 좌수의 변화 | 수건 친구가 가상 펀드의 자산과 주식 수를 같은 비율로 줄여 쌓는다. | 총순자산 100억→90억 원, 좌수 100만→90만. 주당 NAV 1만 원 유지. |
| 원문 화면 | 미국 SEC의 분배금 안내에서 분배 재원 또는 가격 변동 설명을 확대한다. 화면 확보 뒤 지시봉은 원문 바깥에 둔다. | 출처 미국 SEC · 펀드 분배금 안내. |
| 첫 영수증을 다시 쓴다 | 천억이가 실제 관리비 날짜, 주당 NAV, 분배 입금일을 한 줄씩 적는다. | “받을 돈과 오늘 보낼 돈을 따로.” |

가로 만화를 기본으로 쓴다. 세로 보조 카드를 넣을 경우 달러 예시라는 라벨을 그대로 유지하고, 본문의 원화 숫자와 한 화면에서 합산하지 않는다.
