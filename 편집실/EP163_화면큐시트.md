# 은퇴 생활비 1,000만 원 · 화면 큐시트

시간은 지정 Qwen 음성의 실제 줄별 보고서로 확정한다. 가로 만화의 비율과 금액은 공통 0선·별도 숫자 칸으로 유지한다.

| 구간 | 낭독 시작 | 화면 |
|---|---|---|
| 같은 생활비, 같은 매도 버튼 두 개 | L0001 | 청구서의 1,000만 원을 크게 잡고, 증권 화면을 닮은 가상 장부를 두 사람 사이에 놓는다. |
| 시장이 움직이면서 내가 정한 비율도 움직였다 | L0003 | 수건 친구가 주식 7,000만 원과 채권 3,000만 원을 종이에 배치한다. 가상 목표 65%와 실제 70%에 다른 밑줄을 긋는다. |
| 어느 쪽에서 빼도 같은 돈이니 순서를 바꿔 본다 | L0007 | 가로 정보 만화의 3D 막대를 순서대로 확대한다. 같은 9,000만 원을 레몬색, 66.67%와 77.78%를 고대비 라벨로 보인다. |
| 딱 65%를 맞추려면 얼마가 더 움직일까? | L0011 | 원하는 주식 잔액 5,850만 원이 나오는 순간 천억이 얼굴로 전환한다. 150만 원 계좌 안 이동과 1,000만 원 출금을 다른 화살표로 구분한다. |
| 하락장이었다면 질문을 다시 바꾼다 | L0038 | 가상 하락장이 열리면 두 사람의 위치를 바꾼다. 숫자와 축 조건을 옆에 두고 어느 쪽에서 빼는가보다 인출 후 비중을 비교한다. |
| 숫자가 맞아도 병원비 날짜에는 늦을 수 있다 | L0059 | 병원 납부일 달력과 증권계좌의 결제 가능일 카드를 나란히 둔다. 가상 비용 포함 1,002만 원과 손에 들어오는 1,000만 원을 구분한다. |
| 다음 달 인출과 연간 목표를 한 장에 적는다 | L0083 | 외부 정기 입금 200만 원을 영수증에 적고 매도할 돈을 800만 원으로 고친다. 평가액에 이미 든 현금인지도 표시한다. |
| 버튼을 누르기 전에 확인할 한 줄 | L0095 | 천억이가 실제로 쓰는 네 칸 장부를 펼친다. 기존 만화 문구는 출금액, 남은 총액, 목표 비중으로 차례로 확대한다. |
| 편집부 Q&A | L0106 | 청구서로 돌아와 생활비 날짜와 남길 비중을 나란히 놓고 닫는다. |
