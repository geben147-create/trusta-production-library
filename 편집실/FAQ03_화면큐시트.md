# 분배금 2만 원은 어느 칸에 있을까

기존 가로 만화 두 장은 1920×1080이다. 1080×1350 보조 만화는 비율을 유지하고 양옆을 캐릭터와 조건 설명에 쓴다. 아래 순서는 낭독 장 기준이고, 재생 시간은 지정 음성이 생성된 뒤 기록한다.

| 장면 | 화면과 숫자 | 캐릭터 |
|---|---|---|
| 두 앱을 번갈아 열었다 | 큰 가로 컷에서 천억이의 휴대폰 두 화면을 오간다. ETF 평가액 2만 원 감소와 통장의 입금 없음만 번갈아 크게 보여 준다. | 천억이가 특유의 놀란 표정으로 수건 친구에게 휴대폰을 건넨다. |
| 분배 전 장부 | 기존 가로 장부 `권리에서_입금으로.png`의 첫 숫자를 보여 준다. 원금 100만 원, 100좌, 가상 좌당 200원을 영수증에 따로 표시한다. | 수건 친구가 ‘권리 확인’이라는 레몬색 메모를 붙인다. |
| 장부에서 먼저 움직인 숫자 | 98만 원과 받을 2만 원의 합계를 같은 기준선에 표시하고, ‘아직 출금 전’을 짙은 빨간 글씨로 넣는다. | 천억이가 받은 돈 칸에 동전을 옮기려 하자 친구가 달력을 짚는다. |
| 같은 잔액, 다른 현금 | 100만 원으로 출발한 두 주문 영수증을 교차 확대한다. 권리 취득자의 미수 2만 원과 분배락 이후 매수자의 남은 현금 2만 원을 비교하고 가상의 15,000원 지출을 놓는다. | 친구가 분배 권리와 가용 현금을 각각 다른 칸에 적는다. |
| 기준가와 시장가 | 가상의 분배락 전후 가격을 서로 다른 색 선으로 표시한다. 기준가 10,000원 → 9,800원, 시장가 10,050원 → 9,750원. 금액 라벨은 선과 떨어진 무광 칸에 둔다. | 천억이가 화면 중간에 섞여 들어온 다른 가격의 메모를 손가락으로 가리킨다. |
| 실제로 공지는 어디를 볼까 | 기존 가로 원문 `분배락_지급예정_원문달력.png`의 10월 14일, 15일, 19일을 차례로 확대한다. 19일을 지급 예정일로 표기하고 좌당 37원과 다음 회차의 27원은 다른 근거에서 가져온 값이라고 표시한다. | 수건 친구가 빨간 원의 바깥에서 지시봉으로 날짜를 짚는다. |
| 입금 후 다시 주문했다 | 세전 2만 원과 가상 순입금 1만 7천 원을 먼저 대조한다. 별도 세전 사례로 전환해 9,800원 즉시 주문과 일주일 후의 10,200원·9,400원 조건을 시간축으로 비교한다. | 천억이가 입금 내역과 체결 영수증을 서로 다른 날짜 아래에 붙인다. |
| 다음 달 달력에 남긴 것 | 4:5 보조 만화는 가격이 같은 별도 가정임을 자막에 표시한다. 마지막 가로 화면에 권리 날짜, 실제 입금일과 순액, 재투자일을 적는다. | 친구가 달력의 세 칸을 체크하고 천억이는 처음 잔고 화면을 다시 본다. |

공식 지급 일정 원본은 `FAQ03_원자료/삼성운용_지급일정.png`에 보관했다. 출처 자막에는 기관과 자료명만 쓴다.
