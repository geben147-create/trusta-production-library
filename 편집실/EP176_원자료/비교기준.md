# 같은 미국 소형주에 1,000만 원씩, 왜 5년 뒤 236만 원 차이가 났을까?

EP176 캐나다 확장. 공용 진행표에서 IWM, IWN, 소형주 범위 확인. EP014는 전체시장과 대형주 중복, 이 편은 Russell 2000의 기본 소형주 대 가치 스타일의 공시 성과와 2022년 손실. 독자 상황은 퇴직금의 일부를 작은 기업으로 분산할지 배우자와 고민.

2026-11-27 확인.
- [iShares IWM 팩트시트](https://www.ishares.com/us/literature/fact-sheet/iwm-ishares-russell-2000-etf-fund-fact-sheet-en-us.pdf) — 2026-09-30 문서, 2021~2025 달러 NAV 총수익 14.62, −20.48, 16.80, 11.35, 12.69%. Russell 2000 지수.
- [iShares IWN 팩트시트](https://www.ishares.com/us/literature/fact-sheet/iwn-ishares-russell-2000-value-etf-fund-fact-sheet-en-us.pdf) — 동일 기준, 27.96, −14.67, 14.42, 7.74, 12.41%. Russell 2000 Value 지수. 문서 기준 보수 0.19%/0.24%, 기준가 총수익에 이미 반영된 펀드 비용을 재차 빼지 않음.
- [FTSE Russell 스타일 지수](https://www.lseg.com/en/ftse-russell/indices/russell-us-style) — 장부가/가격과 2년 전망 이익 성장, 5년 과거 주당 매출 성장을 스타일 판정에 이용. 현재 공개 방법 개요를 설명하며 과거 모든 규칙이 동일했다고 가정하지 않음. 가치 판정은 상대적인 지수 분류이며 미래 성과/원금 안전 예측이 아님.
- [미 연준 원·달러 참조값](https://fred.stlouisfed.org/series/DEXKOUS) — 2020-12-31 1,086.11원, 2025-12-31 1,444.55원. 이전 편과 동일하며 해당 CSV 직접 대조.

동일한 2020-12-31~2025-12-31, 초기 원화 각 1,000만 원 한 번. 분배 재투자, 중간 납입·인출 없음, 개인 세금·거래·환전비 없음. 달력연도 수익률 배수 연쇄 곱 후 끝과 처음 환율의 비율 적용. 달러 누적 IWM 33.5842%, IWN 51.3073%, 원화 평가 17,766,995원 vs 20,124,199원, 차이 2,357,204원. 2025년만 보면 달러 IWM 12.69%, IWN 12.41%로 순서 역전. 2022년 둘 다 하락. 둘의 수치를 연간 관측이라고 쓰고 최대낙폭과 구분. 특정 상품 안전도 전체 순위를 만들지 않음.
가상 반례: 2022년 연초 각각 USD 10,000 1회, 연간 관측 수익을 반영한 기말 예시 7,952달러와 8,533달러. 해당 시각에 달러 2,000을 생활비로 인출하면 5,952와 6,533달러. 먼저 쓴 금액은 거래 결과와 따로 표시. 반영 수익률은 연간 NAV 총수익 및 재투자 조건, 개인 세금·비용·환율 제외. 이것은 실제 일별 인출 사례가 아님.
