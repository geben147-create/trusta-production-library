# 월세와 은퇴 통장 사이 화면 큐시트

1920×1080. 지정 Qwen 음성에 맞춰 최종 길이를 확정한다.

| 장면 | 화면 |
|---|---|
| 관리비 날짜 | 천억이가 고지서에 표시한 납부일과 리츠 ETF의 분배금을 나란히 놓는다. |
| 두 장부 | 수건 친구가 1억 원 장부를 펼친다. 운영비와 이자는 먼저 색으로 구분한다. |
| 10%에서 20%로 | 가로 만화의 두 번째 막대를 아래에서 보여주고 천억이가 잔액 숫자를 가리킨다. |
| 공실 없이도 | 장부의 가상 이자 칸만 3천만 원으로 바꿔 같은 잔액 결과를 재현한다. |
| 내 통장 | 수건 친구가 공식 분배자료의 좌당 지급액과 지급일을 가리키게 한다. 원문 캡처는 별도 확보한다. |

비교는 가상 원화 건물 단계 현금이다. 실측 리츠 또는 ETF 투자수익률 수치로 옮기지 않는다.
