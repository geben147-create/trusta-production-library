# 장바구니와 은퇴 생활비 화면 큐시트

유튜브 가로 1920×1080. 지정 Qwen 실측 완료 뒤 여덟 장의 시작점을 맞춘다.

| 장면 | 화면 | 숫자·조건 |
|---|---|---|
| 장바구니를 내려놓는 손 | 천억이의 손과 영수증을 먼저 확대하고 집계 화면을 보여 준다. 수건 친구는 식탁 건너편에서 장부를 연다. | “장을 덜 봤는데 카드값이 그대로야.” |
| 뉴스 숫자의 기준 | 천억이가 뉴스 메모 옆에 2025년 연평균이라고 쓴다. | 공식 총지수 전년 대비 +2.1%. |
| 두 가구 | 가로 정보 만화를 크게 쓰고 수건 친구 쪽 말풍선에서 두 가구의 지출 비중으로 이동한다. | 기준 원화 월예산 100만 원씩, 식료품 70%와 30%. |
| 3D 막대 | 전체 0 기준선을 남긴 채 두 숫자 칸을 확대한다. 천억이가 차이 6,400원을 짚는다. | 식료품 +3.2%, 주거 관련 +1.6% 적용. 27,200원과 20,800원은 가상 증가액. |
| 순서 반전 | 수건 친구가 붉은 화살표를 주거 관련 항목으로 돌린다. | 가상 +1%·+5%에서 22,000원과 38,000원. |
| 쌀 포장 | 양손에 든 10킬로그램과 8킬로그램 포장을 가까이 보여 준다. 손 옆의 무광 숫자 칸에 단가를 적는다. | 가상 가격 30,000원과 28,000원. 킬로그램당 3,000원과 3,500원. |
| 원문 가중치 | 공식 분석 사례의 총지수와 식료품·주거 분류를 확대한다. 캡처 확보 시 지시봉과 붉은 표시를 원문 숫자 바깥에 둔다. | 출처 국가데이터처 · 소비자물가지수 분석 사례. |
| 마지막 장부 | 천억이가 두 영수증의 같은 달, 같은 수량을 나란히 적는다. | “내가 많이 쓰는 한 줄부터.” |

기존 가로 만화는 3~4번째 장면에 재사용한다. 공식 캡처가 없는 경우 출처 링크를 원고에 두고 화면에는 출처명을 남긴다.
