# 연금저축의 두 명세서 화면 큐시트

1920×1080. 지정 Qwen 음성 확보 후 화면 시간을 확정한다.

| 장면 | 화면 |
|---|---|
| 마지막 급여명세 | 천억이가 명세서와 연금통장을 펼친다. 수건 친구가 새해의 빈 급여 칸을 가리킨다. |
| 두 공제율 | 가로 만화 첫 장부를 확대해 15%에서 90만 원, 12%에서 72만 원을 보여준다. |

| 실제 돌려받는 돈 | 가상 기납부세액과 최종 세액을 다른 줄로 표시하고 공제할 세액이 없는 경우를 짚는다. |
| 조문 찾기 | 원문 캡처 확보 후 수건 친구가 소득 조건과 납입 한도에 각각 빨간 원을 넣는다. |
