# 퇴직연금 계좌를 만든 지 11년, 왜 세금은 아직 1년차일까?

수건 친구는 계좌 개설 뒤 11년이 지났다는 계산기에 60%를 넣으려 한다. 실제 첫 수령이 올해인 예시에서는 적용하는 실제 수령연차는 1년차다. 예시에서 연금외수령 시 원천징수 기준세율 10%를 가정하고 적법한 연금수령 중 이연퇴직소득 1,000만 원을 비교하면 1년차 국세 70만 원, 실제 11회 과세연도 수령이 확인된 가상 비교 60만 원, 21회면 50만 원. 해당 연금외수령의 가상 국세는 100만 원. 원금에 직접 70·60·50%를 곱하지 않는다.

수령액은 원화, 해당 과세연도 1회 1,000만 원, 모두 이연퇴직소득을 적법하게 연금수령. 수령이 없었던 해는 누적하지 않는 기본 모형. 다른 계좌의 기록을 자동 합산하지 않으며 요건에 맞는 계좌 이전의 예외는 시행령 참조. 계좌 잔액·연율·투자수익 등은 비교에 미사용. 연금외수령 원천징수세율 10%는 실제 납세자의 세율이 아니라 모형 입력. 개인지방소득세, 이전 수령 이력의 세부담, 투자비용·환율·공제 제외. 실제 수령연차가 10년, 20년인 경계는 각각 70%, 60%. 개인 납입·운용수익은 다른 조항 확인. 제20조의3 연금수령 요건을 충족한 범위라는 가정과 별도로 연금수령한도 자체를 계산하지 않음.

법령 화면 시행일 제129조 2026-07-01, 시행령 제187조의3 2026-10-01, 문서 확인 2026-11-27. 실제 적용은 지급 귀속 시점과 금융사 명세 검토. 20년 구간은 현행 조문 설명이며 장래까지 현행이 유지된다는 예측으로 쓰지 않음.
