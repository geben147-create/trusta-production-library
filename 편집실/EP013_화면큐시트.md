# 두 바구니의 미국 비중 화면 큐시트

1920×1080. 실제 Qwen 음성으로 장면 길이를 확정한다.

| 장면 | 화면 |
|---|---|
| 공책의 반쪽 | 가상 인물 천억이가 식탁 공책을 반으로 접어 미국과 세계를 쓴다. 수건 친구가 미국 종이를 세계 쪽에도 붙인다. |
| 50 대 50 | 가로 만화 첫 막대와 천억이의 질문을 강조한다. |
| 80 대 20 | 두 번째 막대와 기준 60%를 띄운다. 수건 친구가 50만 원과 30만 원을 손가락으로 짚는다. |
| 50%로 바뀌는 경우 | 같은 모형에서 가상 세계 바구니를 미국 제외로 교체하며 천억이가 30만 원 표지를 떼어낸다. |
| 팩트시트로 돌아가기 | 원문 화면 확보 후 국가 분류와 기준 날짜에 빨간 원을 넣고 수건 친구를 아래에 둔다. |

가로 만화는 가상 원화 100만 원의 단일 시점 비중 비교다. 실제 특정 ETF의 국가 비중으로 표시하지 않는다.
