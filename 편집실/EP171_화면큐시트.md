# 퇴직한 회사 배당으로 생활비를 낼 때

유튜브 가로 1920×1080. 지정 음성의 행 단위 실측 후 시간을 확정한다. 금액은 원화 가상 예시다.

| 장면 | 컷 흐름 | 화면에 남길 값 |
|---|---|---|
| 마지막 사원증 | 책상에 내려놓는 손을 확대하고, 화면을 넓혀 천억이와 수건 친구가 통장을 보게 한다. | “월급은 끝났고, 배당은 남았네.” |
| 앱 속 두 번째 이름 | 수건 친구가 펀드 목록에서 X를 발견한다. 천억이의 놀란 표정 뒤에 목록을 확대한다. | 직접 4,000만 원 + ETF 간접 800만 원 = X 노출 4,800만 원. |
| 자산이 줄어든 날 | 천억이가 지시봉으로 두 막대의 앞면을 짚는다. 공통 0선 기준의 입체 막대로 전체 평가액을 그린다. | 1억 원 → 8,800만 원. 가상 X 주가 충격 −25%. |
| 통장의 빈칸 | 수건 친구가 지출 220만 원, 고정수입 180만 원 아래에 배당을 적는다. 배당 숫자가 바뀔 때 빈칸을 보여준다. | 월평균 배당 40만 원 → 20만 원. **월 20만 원 부족**. |
| 두 개의 달력 | 위에는 매달 입금, 아래에는 12월 말에만 입금. 두 사람이 11월 청구서를 사이에 놓는다. | 12월 입금 가정에서 11월 말까지 440만 원 필요. |
| 주수를 셀 때 | 동전이나 주식표를 손으로 묶어 옮긴다. 천억이는 같은 잔금 봉투를 들어 보인다. | 240만 원 마련. 주당 4만 원이면 60주, 3만 원이면 80주. |
| 근거 화면 | FINRA 집중 위험 원문의 회사 주식과 ETF 편입 설명을 확대한다. 실제 원문 캡처를 확보한 뒤 캐릭터 옆 빨간 화살표를 표시한다. | 출처는 기관명과 자료명. |
| 돌아온 사원증 | 천억이가 회사 이름 아래 직접 보유·간접 보유·월 부족액을 한 줄씩 적는다. | “내 생활비에는 이 회사가 몇 번 나오지?” |

출처는 FINRA 집중 위험 안내. 금액 산출은 본문 가정에 맞춰 표시하며 막대 위 숫자 영역은 불투명하게 둔다.
