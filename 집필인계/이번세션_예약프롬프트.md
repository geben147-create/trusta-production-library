# 천억뷰 집필 예약

이 대화에서 TRUSTA 천억뷰 대본 프롬프트 담당분만 제작한다. 총 1,000편 가운데 이번 세션 소유는 EP001~EP995 홀수 498개와 FAQ01·FAQ03, 합계 500편이다. 짝수와 FAQ02·04·05는 다른 세션 소유다. 현재 프로젝트 output/TRUSTA_블로그_105편/집필인계에서 분담표와 두 세션 운영 기록을 읽고, 천억뷰_대본_프롬프트_원문.md를 적용한다. 공통기억과 프로젝트 규칙을 먼저 실제 확인한다.
매 예약 호출에서 진행 상태를 먼저 확인한다. 이미 진행 중인 음성·컷·원고의 GPU 작업은 중복 실행하지 않는다. 한 번에 담당 신규 원고 한 편을 실제 집필하거나 기존 짧은 초고를 장문으로 완성한다. 우선순위 EP021·EP061·EP001·EP041·EP051의 이미 검증된 완료 ID는 건너뛰고, 그 뒤에는 초기 100강 마스터의 추천 순서와 FAQ를 따른다. 100강 이후에도 질문·결론·실험이 겹치지 않을 때만 고유 ID를 쓴다. 진행표에서 ‘짧은 초고’와 ‘17분 검증’을 구분하고 보류 원문은 재시도 후 다른 원고도 진행한다. 본문은 한국어 블로그·전자책·낭독 겸용으로, 8단계 하몬 서클, 단계별로 변하는 판단, 가상 인물임을 명시한 생활 장면, 두 조건의 반례와 고유 계산, 원문 출처, 편집부 Q&A를 갖춘다. 표·URL·편집지시·인위적 무음은 낭독에서 제외한다. 최종 음성과 낭독 JSONL은 최신 운영 규칙을 따른다.
지정 9:16 카드와 공유 작업 만화를 먼저 확인한다. 만화에는 1080×1920과 1080×1350이 섞여 있으므로 실제 픽셀을 읽고 4:5는 보조로 분리한다. 본문에 맞는 것만 기간·수치·가정을 대조해 연결한다. 16:9는 도입에 쓰며 기존 재사용을 먼저 검토하고 한 실행에 신규 생성은 필요할 때만 1장 이내로 한다. 빠른 전환은 같은 그림의 크롭·강조·근거 부분 확대·계산 그래프로 만든다. 금융 수치는 법령과 공시·원시계열에서 확인하고 원금·시점·세금·비용·재투자를 밝힌다. 공개 발행·마스터 수정·새 유료 API 호출 없이 로컬 산출물, 담당 상태, 출처, 이미지, 낭독 검산 및 목차를 갱신한다. 편집실/원고기록/ID.json에 해당 편의 정보만 저장하고, 검산 기록에는 실제 사용한 음성과 대본 해시를 구분해 남긴 후 편집실/목차갱신.py로 진행표·목차·EPUB을 갱신한다. 큐시트는 대표편 방식으로 적는다. 다른 세션의 변경을 보존하고 진행 중인 ID를 중복 집필하지 않는다. 담당 500편의 검증 완료가 확인되면 이 예약만 일시정지한다.
최종 배포 매체는 가로 유튜브 1920×1080(16:9)이다. 기존 세로 9:16 자료는 비율을 유지한 근거 화면으로 쓴다. 한 장만 읽어도 답이 나오는 가로 정보 만화에는 천억이와 사용자가 준 수건을 두른 두 번째 캐릭터가 함께 출연한다. 스타일 기준은 집필인계/가로만화_승인스타일.png, 두 번째 캐릭터 원화는 집필인계/수건_캐릭터_사용자원본.png다. 수건 터번과 콧수염·통통한 체형을 살리고 원화의 반복 번호·음표는 콘텐츠 설정으로 가져오지 않는다. 집필인계/천억이_시그니처표정.png의 입을 아주 크게 벌린 표정과 남색 정장 원화(천억이_캐릭터.png)를 그대로 재사용하고, 훅·반전·결말에 자주 반복한다. 추가 가상 여성 캐릭터를 만들지 않는다. 두 인물은 같은 소품을 주고받거나 함께 계산하며 말풍선으로 질문과 답을 나눈다. 매 편 묻는 쪽과 반전을 알아내는 쪽도 장면에 맞게 바꾼다. 비교 기준 낱말은 옅은 레몬색, 판단이 바뀌는 핵심 낱말은 짙은 빨간 글자, 바탕은 중립색이다. B롤·새 이미지 최소. 인스타 전용 원페이지를 별도로 요청받을 때만 프로젝트 4:5 규칙을 적용하고, 유튜브 가로 만화에는 회차 표기를 빼라. 기준 통계와 상품명·티커는 원문으로 확인한다. TTS는 사용자가 지정한 로컬 Qwen3-TTS-Base 자연스러운 v2, 기존 기본 voiceB/한국어를 사용한다. line_id와 text를 담은 순수 내레이션 JSONL을 먼저 쓰고, bash /home/yh/ai-work/tts_cosy_prod/qwen_natural.sh <대본.jsonl> <출력폴더> -12 로 합성한다. 스크립트가 보관하는 full.wav와 report.csv를 사용해 한국어 자막과 큐시트를 맞추고 16:9 H.264/AAC MP4를 로컬 저장한다. 기준 음성으로 대체하지 않는다. 별도 반복 검산은 생략해도 되며 최종 재생길이는 실제 오디오가 있으면 기록한다. 낭독 1.2배속 17분 초과를 목표로 한다. 진행 중인 Qwen 작업은 같은 ID로 중복 실행하지 않으며 GPU가 처리 중이면 다음 담당 원고·만화를 준비한다. 완료되지 않은 음성이나 영상은 완료로 세지 않는다.
출처 칸에는 기관명과 자료명만 표기하며 날짜는 적지 않는다. 관측 기간·기준일은 해당 수치, 그래프 축 또는 본문에 붙이고 자료 확인일은 내부 원고기록에 보관한다. 연속되는 원고나 영상의 만화 형식을 돌려 쓰지 않는다. 각 편마다 한 사건과 소품부터 정하고, 실제 의미에 따라 배경이 보이는 넓은 컷, 손·소품 삽입, 얼굴 클로즈업, 움직이는 액션 컷, 판단이 풀리는 여백과 엔딩을 다른 크기와 순서로 구성한다. 균등한 네 칸 및 같은 표정 스티커의 반복을 피하고, 시그니처 표정은 반전에서 살린다. 캡션과 말풍선, 컷 수·구도는 이야기마다 달라진다. 참고의 인물·대사·사건은 옮기지 않는다.
가로 화면의 주력은 집필인계/주력_생활그래프판단_사용자예시.png의 생활 질문 → 눈으로 읽는 그래프·도해 → 두 인물이 내리는 판단이다. 참고의 문구·수치를 옮기지 말고 매 편의 실제 질문과 원자료로 다시 그린다. 재생시간 기준 약 80%는 이 방식, 10~15%(기본 12%)는 기존 승인 만화의 사건·소품 중심 연출, 나머지(기본 8%)는 해당 편의 실제 거래소·예탁결제원 조회 조건 또는 운용사 공시를 확대하는 짧은 튜토리얼이다. 실제 캡처의 원본·URL은 편집실에 보존하고, 선택할 곳에 빨간 원이나 화살표를 얹는다. 공식 자료가 웹에서 열리지 않으면 같은 기관의 공개 PDF 등 확인 가능한 원문을 쓴다. 실측·가상, 기간, 통화, 분모를 그림 옆에서 읽을 수 있게 하고 가로 1920×1080에 새로 배치한다. 같은 고정 격자를 반복하지 말고 그래프, 장부, 영수증, 투샷, 소품 클로즈업을 의미에 맞춰 교차한다. 출처 칸은 기관명과 자료명만 쓴다.
모든 완성 가로 페이지와 영상 컷은 작은 크기라도 천억이나 수건 캐릭터가 항상 화면에 보이게 만든다. 조회 화면과 원문 팩트시트 위에도 읽어야 할 곳을 지시봉·손가락으로 가리키는 두 인물 중 한 명을 배치한다. 원자료의 숫자와 UI는 가리지 않는다. 차트는 실제 수치로 그린 3D 막대나 두께가 있는 선을 쓰고, 정면 축과 공통 기준선·눈금·숫자 라벨이 가리키는 값은 정확히 보존한다. 피사체·소품·말풍선이 차트 속 결정을 이끌게 해 풍부하고 완성도 있는 한 장의 만화로 연결한다.
최신 시각 기준은 집필인계/만화와_유리차트_사용자참조에 저장한 예시다. 주력은 천억이와 수건 친구가 소품을 함께 다루는 완결된 출판 만화. 사건마다 컷 수와 크기·시점·말풍선 위치를 바꾸고, 고정된 두 열 또는 발표 슬라이드를 반복하지 않는다. 차트는 수치로 만든 실제 입체 기하와 맑은 유리·앰버/블루 크리스털 재질, 곡면 굴절, 우측·좌측·상하 그라데이션, 하이라이트와 접지 그림자를 살린다. 구성비는 분모가 확인되는 경우 원판에, 금액은 같은 단위·기준선의 색 기둥에, 기간 비교는 해당 시간축·달력에 담는다. 유리의 빈 부분과 실제 읽을 값을 구분하고, 비율·금액 라벨과 단위는 무광 고대비 바탕에 둔다. 조회 화면은 원문 캡처를 크게 유지하고, 지시봉·손가락·빨간 원을 흐름 안에 넣는다. 참조의 숫자·상표·외부 인물·대사는 옮기지 않는다. EPUB·웹·영상 모두 같은 데이터와 두 인물의 이야기로 연결한다.

그래프와 타이포 최신 교정. 페이퍼로지 또는 여기어때 잘난체 고딕을 실제 로컬 폰트 파일로 확인해 적용한다. 숫자와 범주 이름은 막대 이미지와 떨어진 불투명한 무광 칸에 굵고 진하게 조판하고, 같은 폭의 전용 칸을 나누어 값·축·말풍선이 겹치지 않게 한다. 차트 축은 정면 공통 0선을 유지하고 막대 자체를 약간 돌려 윗면과 오른쪽 옆면이 함께 보이게 한다. 색 막대 안에는 상단·오른쪽 모서리가 깊어지고 아래·왼쪽으로 밝아지는 다단 그라데이션, 얇은 반사광과 부드러운 접지 그림자를 사용한다. 숫자 크기와 충돌은 최종 가로 PNG뿐 아니라 축소 화면에서도 실제 확인한다. 화면의 금액과 시간축을 정확히 보존한다.

앞으로 천억뷰 담당분의 제목·도입·대표 컷은 실제 투자 결정을 바꾸는 돈 되는 정보 중심으로 편집한다. 부모님께 설명하는 ETF TOP7, 비용·세후·위험을 같은 조건에서 비교하는 피라미드, 7스플릿처럼 진입·현금관리·손실 조건을 배우는 사례를 활용한다. TOP7의 순위는 산정 기준·기간·통화·비용을 명시하고, 실제 과거 수익 순위와 편집부의 확인 우선순위 또는 가상 계산을 구분한다. 기존 원고와 출처를 먼저 재사용하고 수익 보장 없이 금액 차이와 확인할 행동을 쉽게 보여준다. 새 인스타 원페이지는 프로젝트의 1080×1350 및 최신 강조색 기준을 적용한다.

ETF TOP7·7스플릿 등 앞서 잡은 제작과 진행 중인 원고를 이어간다. 후속 에버그린은 같은 시작일·종료일·원금으로 서로 다른 자산과 유사 상품을 비교해 얼마가 남는지 보여준다. 원시계열과 출처를 보관하고 배당 재투자, 통화, 환율, 비용 및 세금의 포함 여부를 명시한다. 가능하면 다른 시작일과 중간 최대낙폭도 검증한다. 2배·3배·100배는 실제 달성 기간과 경로, 선별 편향을 설명하는 과거 사례로 다룬다. 절세·혜택은 공식 조건, 적용일, 순혜택과 제약을 실제 금액으로 제시하고 한시 이벤트는 유효기간을 분리한다.
