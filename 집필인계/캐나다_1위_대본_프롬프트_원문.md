맞아. **지금 부족한 건 전개가 아니라 ‘한국어 입말 레이어’**야. 기존 소스는 리텐션 구조는 아주 좋지만, 한국어 자막 자체가 번역·자동 분절 영향을 받았다고 감사 문서에도 명시돼 있어. 그래서 원본 문장을 그대로 Few-shot으로 복사하는 것보다, **원본의 기능적 리듬을 가져오고 한국 경제 유튜브용 자연스러운 한국어 예문을 새로 만들어 Few-shot으로 넣는 방식**이 더 좋다. 04_AUDIT_REPORT.md

소스의 LANGUAGE ENGINE에는 이미 `시작 → 정상 깨기 → 질문 → 수치 근접 → 반전 → 제한 판정 → 요약 → Callback`이 잡혀 있고, 실제 501개 Beat도 `정보 → 정보 → 짧은 전환 → 질문 → 제한된 답`이 핵심 리듬이다. 01_CONTENT_ENGINE_V2.md 문제는 현재 MASTER가 그걸 **규칙으로만** 갖고 있고, “이 정도로 말하라”는 한국어 Few-shot 샘플이 없다는 거야. 02_MASTER_SCRIPT_PROMPT_V2.md

### 어디에 넣는 게 제일 좋은가

| 파일 | 수정 | 이유 |
|---|---|---|
| `01_CONTENT_ENGINE_V2` | 🟡 최소 수정 | 분석 원본이므로 Few-shot을 잔뜩 넣지 않음 |
| **`02_MASTER_SCRIPT_PROMPT_V2`** | 🔥 **핵심 삽입** | 실제 대본 생성기가 여기이므로 한국어 Few-shot은 여기 |
| 네 `DATA CINEMA 3-MIN MASTER` | 🔥 **한국어 출력 강제 규칙 추가** | 경제·투자 전용 말맛 |
| `03_VISUAL_READY_RULES` | 🟡 자막 줄바꿈 규칙만 추가 | 화면용 한국어 자막 최적화 |
| `04_AUDIT_REPORT` | ❌ 수정하지 않음 | 기존 V2 감사 기록이므로 역사 기록으로 보존 |

그리고 실행 순서도 바꾸는 게 좋다.

**자료조사 → 증거·반전 설계 → Open Loop → Visual Beat → 한국어 초안 → 한국어 Native Rewrite → TTS 입말 검사 → Visual/자막 동기화 → 최종 Fact Check**

특히 지금 MASTER는 STEP 11에서 언어 규칙을 정한 뒤 STEP 14에서 첫 대본을 쓰는데, **대본 작성 후 한국어를 다시 한번 갈아엎는 단계가 없다.** 이걸 하나 넣어야 한다. 02_MASTER_SCRIPT_PROMPT_V2.md

# 🇰🇷 STEP 11-B — KOREAN NATIVE VOICE ENGINE

최종 대본은 단순히 문법적으로 맞는 한국어가 아니라,
**한국인이 실제 YouTube 경제·투자 영상에서 자연스럽게 말하는 한국어**여야 한다.

번역투, 보고서투, 보도자료투를 제거한다.

중요:

**사실은 바꾸지 않는다.  
말하는 방식만 한국어답게 바꾼다.**

---

## 1. 기본 화법

내레이션은 다음 느낌을 사용한다.

**차분한 데이터 다큐**
+
**한국 YouTube 설명 화법**
+
**필요할 때만 짧은 캐릭터 반응**

문어체 100%도 아니고,
친구와 대화하는 반말도 아니다.

기본은 자연스러운 존댓말 구어체다.

예:

“금리가 또 올랐습니다.”

“그런데 시장은 반대로 움직였죠.”

“여기서 숫자 하나만 더 보겠습니다.”

“문제는 그다음입니다.”

“이걸 그대로 믿으면 안 됩니다.”

“왜냐하면 반도체를 빼는 순간 그림이 완전히 달라지거든요.”

---

# 2. 한국어 문장 변환 원칙

## A. 명사 덩어리를 동사로 풀어라

나쁜 예:

“금리 인상에 따른 투자심리 위축 가능성이 존재합니다.”

좋은 예:

“금리가 오르면 투자심리가 얼어붙을 수 있습니다.”

---

## B. 번역투 주어를 반복하지 마라

나쁜 예:

“이는 시장이 금리 상승을 이미 반영했음을 의미합니다.”

좋은 예:

“시장은 이미 금리 인상을 어느 정도 가격에 넣어둔 겁니다.”

또는:

“그러면 얘기가 조금 달라집니다.
시장은 이미 알고 있었다는 뜻이죠.”

---

## C. 화면에 보이는 것을 다시 장황하게 읽지 마라

화면:

`EXPORT +56.0%`

나쁜 내레이션:

“수출은 전년 동기 대비 56.0퍼센트 증가했습니다.”

좋은 내레이션:

“수출이 확 뛰었습니다.
1년 전보다 56%입니다.”

그리고 다음 문장:

“그런데 이 막대를 한번 뜯어보죠.”

---

## D. 한국어는 결론을 뒤에만 두지 않는다

영어식:

“Despite the rate hike, the market rose because…”

번역투:

“금리 인상에도 불구하고 여러 요인으로 인해 시장은 상승했습니다.”

한국어:

“금리는 올랐습니다.
그런데 주가도 올랐죠.

이상합니다.

그날 시장에서는 금리보다 더 센 재료가 하나 있었기 때문입니다.”

---

# 3. 종결어미 리듬

`~습니다`만 계속 반복하지 않는다.

다음을 자연스럽게 섞는다.

- ~습니다.
- ~죠.
- ~겁니다.
- ~인데요.
- ~거든요.
- ~보입니다.
- ~달라집니다.
- ~였던 겁니다.
- ~일까요?
- ~일 수 있습니다.

단,

억지로 모든 문장의 어미를 다르게 만들지 않는다.

### 금지

“입니다. 입니다. 입니다. 입니다.”

가 4문장 이상 연속되는 것.

---

# 4. 짧은 전환문 적극 활용

긴 설명 2~3문장 뒤에는 필요할 경우
짧은 한국어 전환문 하나를 사용한다.

예:

“그런데요.”

“잠깐.”

“여기서 이상해집니다.”

“문제는 이겁니다.”

“그런데 이게 끝이 아닙니다.”

“숫자를 하나 더 보죠.”

“반대로 보면 어떨까요?”

“여기서 첫 번째 설명이 깨집니다.”

“진짜 중요한 건 다음입니다.”

단,
이 표현들을 습관적으로 반복하지 않는다.

**새 정보 또는 의미 변화가 있을 때만 사용한다.**

---

# 5. 숫자를 ‘읽는 한국어’와 ‘보는 숫자’로 분리

정확한 숫자는 화면에 표시할 수 있다.

내레이션에서는 듣기 쉽게 바꿀 수 있다.

화면:

`2,019.8조 원`

내레이션:

“가계가 진 빚은 2천19조 원을 넘었습니다.”

정밀값이 중요한 다음 Beat에서는:

“정확히는 2천19조 8천억 원입니다.”

---

화면:

`47.2%`

내레이션:

“거의 절반입니다.”

다음 Beat:

“정확히 47.2%가 반도체였습니다.”

즉,

**먼저 의미를 말하고,
필요할 때 정확한 숫자를 지급한다.**

---

# 6. 어려운 경제용어 처리

용어를 먼저 정의하지 않는다.

먼저 현상을 보여준다.

나쁜 예:

“DSR은 총부채원리금상환비율로…”

좋은 예:

“연봉은 그대로인데,
매달 갚아야 할 원리금이 커지면 새 대출을 받기 어려워집니다.

이걸 숫자로 제한하는 장치가 DSR입니다.”

# 7. FEW-SHOT — 한국어 경제 DATA CINEMA

**문체·호흡·전환 방식만 학습하기 위한 스타일 예시**다.

실제 영상의 숫자는 반드시 해당 주제의 검증된 자료로 교체한다.

반도체를 빼도 한국 수출은 정말 강했을까요?”

## FEW-SHOT 4 — EVIDENCE INVERSION

금리 발표 뒤,
주가는 오히려 상승폭을 상당 부분 반납했습니다.”

# 8. 번역투 BLACKLIST

다음 표현은 금지어가 아니지만
반복 사용하면 한국어가 급격히 딱딱해진다.

- 이는
- 이러한
- 해당
- ~에 있어서
- ~의 측면에서
- ~라고 할 수 있습니다
- 살펴보도록 하겠습니다
- 주목할 필요가 있습니다
- 결과적으로
- 종합적으로 판단했을 때
- 시사하는 바가 큽니다
- 영향을 미친 것으로 분석됩니다

가능하면 평범한 동사로 다시 쓴다.

예:

“이는 수요 증가를 의미합니다.”

→

“수요가 늘었다는 뜻입니다.”

# 9. TTS READ-ALOUD PASS

초안 완성 후 반드시 소리 내어 읽는다고 가정해 재작성한다.

다음이 있으면 수정한다.

- 한 호흡에 숫자가 3개 이상.
- 조사와 명사가 지나치게 겹침.
- 30자 이상인데 쉼 지점이 없음.
- 같은 종결어미 4회 이상.
- 화면을 보지 않으면 의미가 이해되지 않음.
- 반대로 화면만 보면 내레이션이 완전히 중복됨.
- 혀에 걸리는 영문 약어가 연속됨.
- 괄호가 많은 문장.
- 보고서 제목처럼 들리는 문장.

---

# 10. 한국어 자막 분절

TTS 문장과 화면 자막은 동일할 필요가 없다.

예:

내레이션:

“그런데 반도체를 빼는 순간 한국 수출의 그림이 완전히 달라집니다.”

자막:

“반도체를 빼면?”

→

“수출의 그림이 달라진다”

조사 뒤에서 어색하게 끊지 않는다.

나쁜 줄바꿈:

“반도체 수출이
증가하면서”

좋은 줄바꿈:

“반도체 수출이 증가하면서”

또는:

“반도체 수출 급증”

한 화면에서는
핵심 판단 하나만 남긴다.

# 11. FINAL KOREAN NATIVE CHECK

최종 대본을 출력하기 직전에 확인한다.

K1. 한국인이 실제로 입으로 말할 법한가?

K2. 번역된 영어 다큐처럼 들리지 않는가?

K3. 보고서 문장을 그대로 읽는 느낌이 없는가?

K4. 숫자를 귀로 들었을 때 이해 가능한가?

K5. 캐릭터와 내레이션의 말투가 구분되는가?

K6. 짧은 문장이 실제 전환점에 배치됐는가?

K7. “하지만/그런데/여기서”가 기계적으로 반복되지 않는가?

K8. `이는`, `해당`, `~라고 할 수 있습니다` 같은 문어체가 과도하지 않은가?

K9. 정확성을 유지하면서 문장을 더 쉬운 동사형으로 바꿀 수 없는가?

K10. TTS로 읽었을 때 호흡이 자연스러운가?
